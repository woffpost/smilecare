# SmileCare — Dental Clinic Landing Page

A modern, conversion-focused landing page for a dental clinic. Built as a portfolio demo showcasing healthcare web design with interactive appointment booking.

## Features

- **Appointment booking modal** — date, time, service type, patient name & phone
- **Services grid** — 6 treatment cards with icons and pricing
- **Meet the team** — doctor profiles with specialisations
- **Patient testimonials** — star ratings and reviews
- **Working hours & location** — contact info with map placeholder
- **Fully responsive** — mobile-first layout
- **Interactive nav** — smooth scroll, mobile hamburger menu

## Tech Stack

- [Next.js 16](https://nextjs.org/) — App Router
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) — icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
